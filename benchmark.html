Benchmark Methodology

Evaluation Criteria

  • Correctness (40%) - Does the solution pass all tests and meet requirements?
  • Code Quality (25%) - Readability, maintainability, and adherence to best practices
  • Efficiency (15%) - Time to complete and computational efficiency
  • Robustness (10%) - Handles edge cases and errors gracefully
  • Tool Usage (10%) - Appropriate use of tools and reasoning

Test Environment

All agents are tested in isolated environments with identical constraints. Each task is run 3 times and results are averaged. Time limits are enforced per task category based on complexity.

Data Sources

Our benchmark uses real-world open source issues, actual pull requests, and curated coding challenges from popular repositories across multiple languages including TypeScript, Python, Go, Rust, and Java.
