# Sidebar Layout Plan

## Goal
Define the desired sidebar navigation layout for the Next.js AI chat app (`components/examples/base.txt`).

## User Requirements (confirmed)
1. **Labels:** About, Projects, Contact — as visible text labels (not icons).
2. **Layout:** Stacked vertically, one per line, in that order.
3. **Style:** Exact same style and background as the New Thread button (TooltipIconButton, variant="ghost", size="icon").
4. **Pages:** Each label links to its own blank page (content to be built later).
5. **Order:** About → Projects → Contact → New Thread (preserved last).

## Current State (from code read, before changes)
- Sidebar background: `bg-black` (was changed from original)
